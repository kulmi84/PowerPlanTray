# PowerPlanTray 1.6.2-beta.3

## Deutsch

Diese Vorabversion korrigiert die CPU-Last der Codex-Erkennung und das verzögert bzw. erst nach mehreren Rechtsklicks sichtbare Tray-Menü.

- Codex-Protokolle behalten ihre Leseposition, auch wenn die Sitzung alt ist. Unveränderte alte Dateien werden nicht fortlaufend neu eingelesen. Dateiänderungen werden überwacht; ein periodischer Abgleich fängt verpasste Benachrichtigungen auf.
- Protokolle werden blockweise und mit begrenzter Arbeit pro Durchlauf gelesen. Die Statusanzeige im Menü wartet nicht mehr auf die Dateiabfrage.
- Das Menü wird vor dem Einblenden des Tray-Symbols vorbereitet. Ein von Windows Forms voreingestellter Abbruch wird nach dem Füllen des Menüs zurückgesetzt. Ersetzte Menüeinträge werden freigegeben.
- Prozesslisten werden nur bei aktivierten App-Regeln abgefragt. Zeit- und Hyper-V-Regeln benötigen keine Prozessliste.
- Die Energieplanabfrage verwendet Windows-Power-APIs; `powercfg /list` bleibt nur als Rückfall bei einem Fehler der nativen Auflistung erhalten. Die Planliste wird alle 30 Sekunden aktualisiert, aktive Pläne und Regeln weiterhin ungefähr alle fünf Sekunden.
- Unveränderte Voreinstellungen lösen keine wiederholte Serialisierung und keinen Dateivergleich aus.
- Portable ZIPs enthalten alle veröffentlichten Laufzeitdateien.

Validierung: 63 automatisierte Prüfungen, native Planauflistung mit `powercfg` verglichen, Menüinitialisierung und zehn Öffnungsereignisse geprüft. Die vorherige Beta 2 lag auf dem Testgerät in einer 20-Sekunden-Messung bei durchschnittlich 0,1171 % Prozess-CPU auf sechs logischen Prozessoren. Das ist keine Messung der neuen Beta 3.

### Installation

- Portable Standard-/Codex-ZIP vollständig entpacken. Eine laufende ältere Instanz vorher beenden.
- Das lokale MSIX-Testpaket nutzt `PowerPlanTray.LocalTest`, Paketversion `1.6.13.0`. Es verwendet dasselbe öffentliche Testzertifikat wie 1.6.2-beta.1/2; bei einem Update von diesen Versionen ist kein neuer Import nötig. Die bestehende Beta zum Aktualisieren beenden, nicht deinstallieren.
- Die offizielle Store-Ausgabe verwendet die in `packaging/store-identity.json` dokumentierte Produktidentität. Sie ist von der lokalen MSIX-Testausgabe getrennt und übernimmt deren Einstellungen nicht automatisch. Ein erfolgreicher Paketbuild bedeutet noch keine Store-Veröffentlichung.
- Codex-Erkennung bleibt bei frischen Einstellungen ausgeschaltet.

## English

This prerelease fixes excessive Codex-monitor CPU use and the tray menu requiring additional right-clicks.

- Preserve session log offsets instead of repeatedly replaying stale logs; monitor file changes with periodic reconciliation.
- Read bounded blocks and let the tray menu read status without waiting for filesystem work.
- Prepare the menu before showing the tray icon, reset the initial Windows Forms cancellation after populating it, and dispose replaced items.
- Sample processes only when an app rule is enabled. Use native power APIs and cache plan names for 30 seconds; active plan and rule checks remain at approximately five-second intervals.
- Avoid repeatedly serializing and comparing unchanged settings. Include all published runtime files in portable archives.

63 automated checks passed, native plan enumeration was compared with `powercfg`, and startup plus ten menu opening events were checked. The reported 0.1171% average CPU sample was measured on beta 2, not beta 3.

Extract portable ZIPs completely and close the old instance first. The local MSIX (`PowerPlanTray.LocalTest`, package `1.6.13.0`) updates beta 1/2 with the same test certificate. The official Microsoft Store identity is separate and does not automatically import local-test settings. Codex monitoring remains off for fresh settings.
