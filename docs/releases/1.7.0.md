# PowerPlanTray 1.7.0

## Deutsch

- Optionaler Standby-Schutz für Claude Code im Terminal und im Code-Tab der Claude-Desktop-App, soweit lokale Claude-Code-Protokolle vorliegen. Gewöhnliche Claude-Chats werden damit nicht überwacht.
- Claude und Codex lassen sich getrennt einschalten und haben jeweils eine eigene Nachlaufzeit (5, 10, 15, 30 oder 60 Minuten). Beide Erweiterungen sind bei frischen Einstellungen ausgeschaltet.
- Prompts, Werkzeugaufrufe und Ergebnisse in Claude-Code-Protokollen melden Aktivität; ein reguläres Aufgabenende startet den Nachlauf. Der Abschluss eines Subagenten innerhalb des Hauptprotokolls beendet die Hauptaufgabe nicht.
- Claude-Aufgaben ohne weitere Protokollaktivität werden nach 15 Minuten nicht mehr als aktiv gezählt. Bei Codex bleibt die Frist fünf Minuten. Auch ein tatsächlich laufender Vorgang ohne neue Arbeitsereignisse kann diese Frist erreichen; neuer Fortschritt erneuert die Sperre.
- Die Auswertung erfolgt lokal. Verwendet werden Datensatztypen, Statusfelder und Zeitstempel; Prompt- und Antworttexte werden nicht für die Erkennung verwendet, gespeichert oder übertragen.
- Die gemeinsame Überwachungslogik behält die bisherigen begrenzten Lesevorgänge und die sofort abrufbare Tray-Statusanzeige bei.

Validierung: 81 automatisierte Prüfungen erfolgreich. Zusätzlich wurde die tatsächliche Windows-Energieanforderung anhand synthetischer Protokolle geprüft: Aktivität und Nachlauf sperren; ein abgelaufener Nachlauf und verwaiste Aufgaben geben frei; Ausschalten gibt frei, ohne eine zweite aktive Anforderung zu beenden.

Portable ZIPs vollständig entpacken; ältere laufende Instanzen vor einem Update beenden. Die Standard-Ausgabe enthält keine Agenten-Überwachung. Die Datei mit dem Namenszusatz `Codex` enthält die optionalen Erweiterungen für Codex und Claude Code.

Die offizielle Store-Ausgabe verwendet Paketversion `1.7.0.0` und die Identität aus `packaging/store-identity.json`. Ein erfolgreicher Build bestätigt noch keine Store-Veröffentlichung.

## English

Optional Claude Code sleep protection now works alongside Codex protection, with separate switches and grace periods. Both are off by default. Claude Code terminal sessions and the desktop app's Code tab are supported when local Claude Code logs are available; ordinary Claude chats are not monitored.

Claude activity expires after 15 minutes without work records, while Codex retains its five-minute limit. A real task with no logged progress can also expire; new work renews protection. Normal completion starts the selected grace period. Processing remains local and does not use prompt or response text for detection.

81 automated checks passed. Additional Windows power-request checks covered activity, grace, expired grace, orphaned tasks, disabling protection and independent requests.

Extract portable archives completely and close older instances before updating. The standard ZIP contains no agent monitoring; the Codex ZIP includes optional protection for both agents. The official Store package version is `1.7.0.0`, subject to Microsoft certification.
