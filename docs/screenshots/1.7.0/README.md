# PowerPlanTray 1.7.0 screenshots

The JPEG files are original Windows captures of the actual 1.7.0 SettingsForm and AboutForm. Example plan names are used. No user settings were saved and no real sleep-protection request was activated while taking these screenshots.

The `extensions-default` views show fresh settings; the `extensions` views show both extensions selected as an example. Each extension has its own grace period.

The settings and extension views were recaptured on 4 November 2026 with the pointer outside the product window, so no pointer or mouse-highlight effect appears in the images.

The `store-*.png` files frame the original captures with localized headings at the Microsoft Store desktop minimum of 1366 × 768. The underlying app view is shown at its original size without changing its controls or text. The matching HTML files are the frame sources.
